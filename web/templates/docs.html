Use HTTP Basic auth with client_id:client_secret. Client secrets are shown only when created or rotated. The legacy bearer admin key remains available only while LEGACY_ADMIN_API_KEY_ENABLED is true.

curl -u "$CLIENT_ID:$CLIENT_SECRET" \
  -H "Content-Type: application/json" \
  http://localhost:8080/api/v1/secret-links
